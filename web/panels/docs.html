Welcome to Cordova Pro GUI

A professional, user-friendly interface for Cordova project management.

Quick Start

  1. Create a new project - Use the Project Manager panel
  2. Add platforms - Android, iOS, Windows, etc.
  3. Install plugins - Add functionality to your app
  4. Build & Run - Build and test your app

Features

  • Project Management - Create, open, and manage projects
  • Platform Management - Add/remove platforms easily
  • Plugin Management - Install/uninstall plugins
  • Config Editor - Visual config.xml editing
  • Build System - Build and run your apps
  • Modern UI - Clean, responsive, and user-friendly
  • Dark/Light Mode - Switch between themes
